# Index.md v2 + sync-index.mjs 实施 Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **TDD 约束**（CLAUDE.md 硬要求）：Task 2（测试）必须**先于** Task 3（实现）完成并跑红，再写实现跑绿。
>
> **commit 粒度约束**：每个 task 末 = 一个 atomic commit + Log.md 末尾按 [00_模板/Log_Spec.md §3.1](../../../00_模板/Log_Spec.md) 追加条目。

**Goal:** 用 `scripts/sync-index.mjs` 确定性维护 vault 根 `Index.md`，把 02/03/11/12 全部路由进同一张目录表（Karpathy "everything in the wiki"），LLM/skill 不再手写表格。

**Architecture:**
- 单一职责 `scripts/sync-index.mjs`：CLI + pure-function 库（parse / scan / render / merge）
- 标记块包裹法：`<!-- sync-index:begin v2 -->` ... `<!-- sync-index:end -->`，块内脚本全权负责，块外用户段保留
- init-vault 拷贝 `Index_Skeleton.md` 到 vault 根作为带空标记块的骨架
- lint-wiki 新增 2 类检查复用 sync-index 的 scan/render 函数

**Tech Stack:**
- Node.js 22+ `node:fs/promises` / `node:path` / `node:test` / `node:util`
- ESM `.mjs`，与 `init-vault.mjs` / `sync-pdf-notes.mjs` 同风格
- 外部依赖：灰度（gray-matter 用于 frontmatter 解析，**决策点见 Task 1**）

**Spec:** [docs/superpowers/specs/spec-index-v2.md](../specs/spec-index-v2.md)

## 决策点（Task 1 开工前必须确认）

| # | 决策点 | 推荐 | 备选 |
|---|--------|------|------|
| 1 | frontmatter 解析 | **手写最小解析器**（仅支持 v1 spec 字段：`文章:` `tags:` `title:` `concepts:`）| A. 引入 `gray-matter` 依赖；B. 复用 `init-vault.mjs` 的解析逻辑 |
| 2 | "关键概念"列分隔符 | ` / `（斜杠+空格）| `,`（逗号）|
| 3 | 缺失 `tags:` 时显示 | `—`（em dash）| 空字符串 |
| 4 | 缺失 `文章:` / `title:` 时显示 | 文件名（去 `.md`）| `—` |
| 5 | Entities / Concepts 段排序依据 | frontmatter `title:` | 文件名 |
| 6 | 主题段排序依据 | frontmatter `文章:` | 文件名 |
| 7 | 标记块 id | `v2`（语义化版本号）| `default` |
| 8 | `--check` 行为 | 输出 unified diff + exit 1（CI 可用）| 输出错误 + exit 1 |

**决策 1 推荐手写解析器**：
- v1 spec 只用到 4 个字段，写 ~30 行解析器足够
- 不引入依赖，符合 [AGENTS.md (atomicstrata/atomicmemory)](https://github.com/atomicstrata/atomicmemory/blob/main/AGENTS.md) "Keep adapters and plugins thin. ... Do not add a crate for a small utility" 精神
- 与 [scripts/init-vault.mjs](../../scripts/init-vault.mjs) 已有的 frontmatter 处理保持风格一致
