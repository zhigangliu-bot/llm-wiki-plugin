# 笔记标签词表

仓库标签体系的 single source of truth。skill / 脚本 / sub agent 必须从此处读取枚举值，新增/修改枚举请直接改本文件。

## 1. 设计原则

- **四轴扁平**：每篇笔记最多 4 个 axis，每个 axis 可选 1 个或多个值
- **前缀命名空间**：`<axis>/<value>` 格式（如 `domain/ai`），Obsidian YAML 不解析为 map key，机读友好
- **显式枚举**：禁止自由 tag，所有取值必须在本表内
- **单值优先**：除 `phase` 外，其他 axis 建议单值；`phase` 可多值（如需求+验证同时存在）
- **domain 软上限**：单篇 `domain` 建议 ≤ 2 个，最多 5 个（跨学科交叉如 `ai + enterprise-it` 常见，再多会让 Dataview 切片失去区分度）。脚本不强制，由人工 review 把握
- **maturity 单值必填**：用于判断笔记权重，`concept < research < pilot < production < standard`

| `concept` | 概念子类（§4） | 4 轴 / 实体子类 |
