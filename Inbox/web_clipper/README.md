# Web Clipper

浏览器剪藏的网页 / 文章暂存区。Obsidian Web Clipper 浏览器扩展默认把抓取内容写到这里,再由 obsidian-collacting skill 统一入库到 `02_读书笔记/`。

## 使用建议

- 每次 clip 后,在该笔记 frontmatter 补 4 轴 tags(domain / layer / phase / maturity)+ `source: "[[01_知识库/...]]` 链回原 PDF(若有)
- 处理后建议把该 md 移到 `02_读书笔记/` 对应子目录,本目录保持空
- 长期未处理的 clip 文件可定期清理(已超过 30 天且未引用)
